# Бот напоминаний о записи для салона

Клиент получает в Telegram напоминание за сутки до визита и нажимает «Приду» или «Не смогу». Администратор сразу видит ответ и может занять освободившееся время.

## Запуск за 5 минут

1. Откройте в Telegram @BotFather, отправьте `/newbot`, придумайте имя и получите токен.
2. Установите Python 3.10+ и зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в файл `.env` и впишите `BOT_TOKEN` и название салона.
4. Запустите бота и напишите ему `/myid`. Он ответит вашим Telegram ID. Впишите его в `ADMIN_IDS` (администраторов может быть несколько, через запятую) и перезапустите бота:
   ```
   python bot.py
   ```

## Как пользоваться (администратор салона)

| Команда | Что делает |
|---|---|
| `/new 25.11 15:00 Анна \| маникюр` | создаёт запись и выдаёт готовое сообщение со ссылкой для клиента |
| `/list` | показывает ближайшие записи и кто ещё не подключил бота |
| `/cancel 3` | отменяет запись №3 и уведомляет клиента |
| `/myid` | показывает ваш Telegram ID |

Порядок такой: создали запись, отправили клиенту ссылку (в Instagram, по SMS, как угодно), клиент нажал «Старт». Дальше всё автоматически.

## Важно знать

- **Клиент должен один раз нажать «Старт» по ссылке.** Telegram не разрешает ботам писать людям первыми. Поэтому ссылку лучше отправлять сразу при записи.
- Если клиент ещё не подключил бота, в `/list` рядом с записью будет пометка. Таким клиентам стоит напомнить вручную.
- Если запись создана меньше чем за 24 часа до визита, напоминание уйдёт сразу после того, как клиент нажмёт «Старт».
- Бот хранит только имя, услугу, время и Telegram-идентификатор чата. Телефоны не собираются.
- Время считается по Киеву (`Europe/Kyiv`).

## Где держать бота, чтобы работал всегда

Пока на вашем компьютере запущен `python bot.py`, бот работает. Если компьютер выключен, напоминания не уходят. Для постоянной работы нужен сервер, который включён круглосуточно (недорогой VPS или бесплатные тарифы хостингов для небольших приложений). Для пилота на 1-2 салона можно запускать на своём компьютере в рабочие часы.

## Что можно добавить дальше

- напоминание ещё и за 2 часа до визита;
- повторное напоминание, если клиент не ответил;
- запись от самого клиента через бота (выбор услуги и времени);
- отдельные настройки для нескольких салонов;
- простая статистика: сколько напоминаний ушло и сколько клиентов подтвердили.
